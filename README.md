# YOLO Human Tracking Dashboard

Real-time human detection, tracking, and counting dashboard using YOLO, ByteTrack, OpenCV, and Streamlit.

---

## Features

- Real-time Object Detection
- Human Tracking with Unique IDs
- Human Counting System
- Streamlit Dashboard
- Video Upload Support
- Bounding Box Visualization
- Counting Line Detection

---

## Technologies Used

- Python
- YOLO
- OpenCV
- Streamlit
- ByteTrack

---


## How It Works

1. Upload a video file
2. YOLO detects humans in each frame
3. ByteTrack assigns tracking IDs
4. System counts humans crossing the line
5. Dashboard displays processed video output
---

## Output

- Real-time tracking
- Human counting
- Bounding boxes with IDs
- Processed video visualization
---
