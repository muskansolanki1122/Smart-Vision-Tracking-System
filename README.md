# YOLO Object Detection + Tracking Dashboard

Real-time object detection and tracking dashboard using YOLO, OpenCV, and Streamlit.

## Features

- Object Detection
- Object Tracking
- Human Counting
- Streamlit Dashboard
- Video Upload Support

## Technologies Used

- Python
- YOLO
- OpenCV
- Streamlit

## Run Project

```bash
pip install -r requirements.txt
streamlit run app.py
